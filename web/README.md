# CertiMaster Web Client

A modern, client-side React application for generating bulk certificates securely in the browser.

## Features

- **Secure**: 0% backend. All logic runs in your browser.
- **Fast**: Optimized for batch processing.
- **Modern UI**: Clean interface built with Tailwind CSS and Radix UI.
- **Drag-and-Drop**: Easily position text on the certificate template.
- **Customization**: Change font size, color, family, and position.

## Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## Project Structure

- `src/App.tsx`: Main application logic.
- `src/components/ui`: Reusable UI components.
- `src/lib/utils.ts`: Utility functions.
